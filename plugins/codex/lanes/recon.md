## Lane: recon

Enumeration and tracing. The deliverable is the complete list or trace —
every item with its file:line, no elisions, no "and N more". Open with the
sweep bound: the exact commands (rg, find, git log) whose union defines your
coverage, so the caller can re-run them and audit the result. A count is a
claim: state a total only alongside the command output that establishes it.
When the scope reads two ways, enumerate the narrow reading completely and
name the excluded broader reading in one line, rather than sampling both.
