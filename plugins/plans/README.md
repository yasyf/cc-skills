# plans

One skill, `plans`, for work done in Claude Code's plan mode.

- A plan has five sections: Context, Approach, Potential Pitfalls, Workflow
  Plan and Verification. Every fix step names the files and symbols it
  changes.
- When a code review re-enters plan mode, every comment is carried verbatim
  and mapped to a fix step.

Install:

```
claude plugin install plans@skills
```
