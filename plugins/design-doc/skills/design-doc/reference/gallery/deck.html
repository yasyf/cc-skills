What this costs, and where to push back

What this costs

  • Every producer sets an idempotency key.
  • One SQLite file per tenant to back up and restore (V2).
  • An archive in object storage, 24 hours behind.

Where to push back

  • Every consumer can absorb a duplicate; nobody has confirmed it in writing (A1).
  • Lease renewals on the dispatch connection or their own endpoint (DQ4, V3).
  • Scheduled jobs are not designed here (Q2).
